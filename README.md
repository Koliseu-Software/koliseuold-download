# KoliseuOld — download do cliente

Cliente oficial do **KoliseuOld** (Tibia 8.0). Site: https://koliseuold.com.br

## Como instalar

1. Abra a página [Releases](../../releases/latest) e baixe `KoliseuOld-Setup.exe`.
2. Execute o instalador. Ele instala para o seu usuário, sem precisar de administrador.
3. O Windows pode mostrar o aviso do SmartScreen ("O Windows protegeu o computador"). Clique em **Mais informações** e depois em **Executar assim mesmo**.

Prefere sem instalador? Baixe `KoliseuOld-1.1.zip`, extraia numa pasta e abra `KoliseuOldClient.exe`.

O cliente se atualiza sozinho ao abrir, então não é preciso baixar de novo a cada versão.

Este repositório tem apenas os arquivos de download. O código do jogo não está aqui.
